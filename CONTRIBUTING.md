# Contributing

## Branch

- Never commit or push to `master` (or `main`).
- Work on `tipo/escopo-curto`: `feat/home-catalog`, `fix/room-migration-v2`, `test/lists-ui`, `chore/ci-jacoco`, `docs/readme-portfolio`.
- One feature / one phase = one branch = one PR.
- Update a feature branch with `git fetch && git rebase origin/master`. Never rebase `master` itself. Never `--force` `master`. `--force-with-lease` only on your own feature branch when requested.

## Commits

Conventional Commits, imperative subject, ≤ 72 characters:

```
feat(shop): add offline cart persistence
fix(maps): request location only after grant
test(lists): cover empty and error states
```

Types: `feat`, `fix`, `test`, `refactor`, `docs`, `chore`, `ci`, `perf`.

- Author is the local git user. Do not skip hooks unless asked.
- Body only when the *why* is not obvious.
- After a slice of work is done, **stop**. Show the diff and wait for the author to review before any commit. Do not commit or push until they ask.

### Forbidden in subject and body

- `Co-authored-by:` (including Cursor / any agent)
- `Signed-off-by:` for an AI agent
- “Generated by Cursor”, “via Cursor”, “AI-assisted”, or equivalent

If a hook injects `Co-authored-by` on a commit you just created and it is not pushed, amend that HEAD only to strip the trailer.

## Pull requests

- Title uses the same Conventional Commits format.
- Body: Summary + Test plan.
- Merge only via PR. No direct commits on `master`.
